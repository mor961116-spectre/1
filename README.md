# 📖 角色Wiki - 互動式人物百科

一個現代化、互動式的角色介紹網站，結合了Wiki風格的詳細資訊和吸引人的用戶體驗。

## ✨ 功能特色

### 🎯 核心功能
- **歡迎彈出視窗**：用戶首次進入時會看到一個精美的歡迎彈窗，增強互動性
- **角色卡片網格**：以視覺化的卡片展示所有角色，每張卡片包含角色基本資訊
- **詳細資訊面板**：點擊角色卡片可查看完整的背景故事、性格特點、能力等詳細資訊
- **搜尋功能**：支援按名字、身份或描述搜尋角色
- **響應式設計**：完美適配桌面、平板和手機設備

### 🎨 設計亮點
- 現代化的紫色漸變配色方案
- 流暢的過度動畫和互動效果
- 毛玻璃效果（Glassmorphism）的導航欄
- 清晰的視覺層級和易用的界面

## 🚀 快速開始

### 方法1：使用GitHub Pages（推薦）

1. 在您的GitHub儲存庫設定中啟用 GitHub Pages
2. 選擇 `main` 分支作為發布源
3. 訪問 `https://mor961116-spectre.github.io/1/` 查看您的網站

### 方法2：本地運行

1. 克隆或下載此儲存庫
2. 在項目文件夾中開啟 `index.html`
3. 在瀏覽器中開啟並開始探索！

## 📝 如何添加新角色

編輯 `script.js` 文件中的 `characters` 陣列，按照以下格式添加新角色：

```javascript
{
    id: 7,
    name: "角色名稱",
    emoji: "💎",              // 使用emoji或其他符號
    role: "職業/身份",
    description: "簡短描述",
    background: "背景故事",
    personality: ["特點1", "特點2", "特點3"],
    abilities: ["能力1", "能力2", "能力3"],
    story: "冒險故事"
}
```

## 🎮 使用指南

### 瀏覽角色
1. 頁面加載時會自動顯示歡迎彈窗
2. 點擊「開始探索」或關閉彈窗開始瀏覽
3. 滾動查看所有角色卡片

### 查看詳細資訊
1. 點擊任何角色卡片
2. 查看完整的背景故事和詳細資訊
3. 點擊「返回」按鈕回到角色列表

### 搜尋角色
1. 在導航欄的搜尋框中輸入
2. 支援按角色名稱、職業或描述搜尋
3. 搜尋結果會實時更新

## 🛠️ 自訂選項

### 修改顏色方案
在 `styles.css` 中找到漸變顏色定義：
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### 修改歡迎彈窗內容
編輯 `index.html` 中的 `welcomeModal` 部分

### 調整卡片網格
在 `styles.css` 中修改 `characters-grid`：
```css
grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
```
